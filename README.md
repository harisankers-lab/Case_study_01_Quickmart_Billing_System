# Retail Billing System | Python

A console-based retail billing system developed using Python, demonstrating modular programming and basic billing operations.

### Features
- Item-wise total and cart subtotal calculation
- Discount and GST calculation
- Category wise sales summary
- Top selling item analysis
- Formatted billing receipt generation

### Concepts Practised
Functions, modules, lists, dictionaries, lambda functions, list comprehensions and data processing.

### Project Structure
- `quickmart_billing.py` – Main program execution
- `quickmart_billing_fns.py` – Reusable billing functions
